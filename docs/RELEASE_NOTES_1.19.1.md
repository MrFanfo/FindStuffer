# Findstuff 1.19.1

The single Item view now puts **Find manual** and **Find details** as small
buttons at the top of **More**. The large **Find online** section has been
removed from **Details**. Both review workflows still behave as in 1.19.0:
PDF manuals are downloaded and saved as Item documents when you choose
**Attach PDF manual**; web guides can be saved as links, and product fields
are selected before saving.

No database migration is needed when upgrading from 1.19.0. Update through
**Settings → Software update** after this release's container image is
published.
